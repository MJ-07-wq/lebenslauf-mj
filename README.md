#Portfolio 

My personal portfolio website built from scratch using HTML, CSS and JavaScript.

The goal of this project was not only to create a website about myself, but to build a complete, responsive and modern portfolio that represents my interests in software development, web development, media technology and digital content creation.

Live Website:
https://mj-07-wq.github.io/lebenslauf-mj/


## Project Background

The project started as a redesign of my previous personal website.

The original version worked, but the individual pages had different designs and the overall website did not feel consistent or professional enough.

The goal was therefore to rebuild and improve the website step by step while keeping the project as a learning experience.


## Goals

The main goals of the project were:

- Create a modern and consistent design
- Build a responsive layout for desktop, tablet and mobile
- Present my skills, education and projects
- Create a professional online portfolio
- Improve my HTML, CSS and JavaScript skills
- Experiment with animations and interactive elements
- Support both English and German
- Publish the website using GitHub Pages
- Make the website discoverable through Google


## Technologies

The website was built using:

- HTML5

- JavaScript
- Responsive Web Design
- CSS animations and transitions
- Git & GitHub
- GitHub Pages


## Features

### Responsive Design

The website adapts to different screen sizes and includes a mobile navigation system.

### Animations

Several animations and micro-interactions were implemented, including:

- Scroll reveal animations
- Hover effects
- Button animations
- Card glow effects
- Animated gradients
- Terminal animations
- Floating elements
- Skill interactions

### Interactive Terminal

The homepage contains a terminal-inspired `portfolio.exe` element that visually represents the technical theme of the portfolio.

### Language Switch

The website can switch between English and German using JavaScript.

Instead of maintaining two separate versions of the website, the content is translated dynamically.

### Skills

My technical and creative skills are presented using interactive cards and skill tags.

Technologies or areas that I am still learning can also be marked as "Coming Soon".

### Education Timeline

The education page presents my educational journey as a visual timeline.

### Projects

The projects section provides an overview of personal, school and creative projects.

### Contact

A dedicated contact page provides ways to reach me and links to my online profiles.


## Design

The visual identity of the website is based on a dark technology-inspired interface.

The main design uses:

- Dark navy and black backgrounds
- Blue and turquoise accent colours
- Glass-style cards
- Subtle gradients
- Glow effects
- Terminal-inspired elements
- Rounded UI components

The goal was to combine a professional portfolio with my own personality instead of using a standard portfolio template.


## Problems & Improvements

During development, several problems appeared and were fixed step by step.

Some examples:

- Buttons unexpectedly changing size when clicked
- Hover effects overflowing outside cards
- Images not blending correctly with the website background
- Inconsistent styling between different pages
- Mobile navigation issues
- Language switching initially translating only parts of the website
- GitHub Pages displaying an older or incorrect version
- Sitemap accessibility and Google indexing

Finding and fixing these problems became an important part of the project.


## SEO & Google Search

After publishing the website through GitHub Pages, basic search engine optimisation was implemented.

This included:

- Page titles
- Meta descriptions
- Sitemap (`sitemap.xml`)
- Google Search Console
- Manual indexing request
- HTTPS through GitHub Pages

The website was successfully submitted to Google and indexed.
